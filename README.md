# DigitalFlake Fullstack Hackathon Assignment

This project is built as part of the DigitalFlake 8hrs Job Hackathon 2025.  
It is a full-stack application developed using **React.js, Node.js, Express.js, and MongoDB**.

---

## 🚀 Features

- User Authentication (Register / Login) using JWT
- Secure password hashing with bcrypt
- Add, Edit, Delete items
- Search functionality
- Responsive modern UI
- Protected routes
- RESTful API integration

---

## 🛠 Tech Stack

**Frontend:**
- React.js
- Axios
- CSS (Custom styling)

**Backend:**
- Node.js
- Express.js
- JWT Authentication
- bcrypt
- MySQL
